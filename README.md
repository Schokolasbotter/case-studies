### [Fish AI for *The Lakelings*](derailed-arts-the-lakelings.md)
**Derailed Arts · February – June 2025 · Unity / C#**

My first professional games role. I owned all fish behaviour in the wild — Laban-Effort-driven
movement, a sensing system, a utility layer over a finite state machine, population management,
and 3D underwater navigation via a voxel grid and A\*.

The prototype was demoed at Develop Brighton and Brilliant Indie Treasures.
